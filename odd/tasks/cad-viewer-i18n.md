# cad-viewer i18n

Multi-language support for the viewer, its components and the sandbox: Spanish (Spain) first, English second.
Branch `feat/i18n` from `main` at v0.1.0 (`465de0b`). Released as **0.2.0**: PR [#2](https://github.com/jesusjbriceno/cad-viewer/pull/2) merged with a merge commit `b8e2952` (parents `465de0b`, `54e12ab`), annotated tag `v0.2.0` and GitHub Release https://github.com/jesusjbriceno/cad-viewer/releases/tag/v0.2.0.

## Specs

- **S1** — "soporte multi-idioma con español de España como idioma principal y secundario inglés"
- **S2** — "Superficies a cubrir: textos visibles del core (aria-label del canvas, etiqueta de medición, mensajes), una opción `locale` en `CadViewer` y en los componentes Vue y React (por defecto `es-ES`, con fallback a `en`), la UI del sandbox con selector de idioma, y la documentación de cómo usarlo."
- **S3** — "Mantén la API retrocompatible o márcalo como cambio de versión menor."
- **S4** — Library error messages (`CadLoadError`, "Unknown layer…", etc.): "¿se traducen directamente o pasan a códigos estables con un texto traducido aparte?" Decision: "Códigos estables + texto traducido aparte (Recomendado)" — every library error carries a stable `code` and `params` (new `CadViewerError extends Error`; `CadLoadError` already has `code`); `error.message` stays in English and unchanged; the UI gets the es-ES/en text through `viewer.formatError(error)` or `formatCadError(error, locale)`. Backward compatible → 0.2.0.
