# Sample files — sources and licenses

Every file in this directory is redistributed under **CC0 1.0 Universal** or **CC BY**.
`Samples.json` (this folder) is the machine-readable record; `test/samples.test.ts` fails if
this file and the manifest disagree, if a listed file is missing, or if a SHA-256 does not
match.

## Licensing notes

- **CC0-1.0** files carry no attribution requirement; they are credited here anyway so the
  provenance stays auditable.
- **CC BY** files would require visible attribution in the sandbox: the credits page lists
  every entry (title, author, license and source link) and is generated from the manifest, so
  a CC BY entry is attributed automatically. No CC BY asset is bundled today.
- Do not add a file whose license is unknown, GPL, or CC BY-SA here. Those need their own
  isolated directory and an explicit decision, the same way the DWG plugin is isolated.

## Provenance checks

- Innerscene's Free Parts Library releases contributions under CC0 1.0
  (<https://www.innerscene.com/tools/library/terms>, read 2026-10-17).
- Falcon documents every sample's license on its samples page and marks these three as
  "Generated by Falcon — public domain (CC0)" (<https://falcon.so/resources/samples>, read
  2026-10-17).

## Regenerating

`node examples/sandbox/scripts/prepare-assets.mjs` copies this folder into
`examples/sandbox/public/samples/` for the dev server and the static build. The files
themselves are committed; nothing is downloaded at build time.
