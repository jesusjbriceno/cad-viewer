## Summary

The 3D viewer can now orbit the **3D faces a drawing already carries**.

- **`sceneFromDocument(document, { layout? })`** in `cad-viewer-3d` turns the `3DFACE` entities of
  a DXF/DWG into a `CadScene`: one mesh per layer, two triangles per quad, `Z` preserved, bounds
  computed. Plain `SOLID`/`TRACE` fills and every other entity are ignored.
- **`has3dFaces(document)`** lets a host decide whether to offer "view in 3D" before building a
  scene.
- Both are pure functions over the existing neutral model: **no new dependency**, MIT, no server,
  and no change to the 2D path (`3DFACE` keeps being drawn flat by the 2D viewer).

`3DSOLID` (ACIS B-rep) is explicitly **out of scope** here: it needs a converter, which is a
separate decision recorded in `odd/tasks/cad-viewer-backend.md` (options A/B/C, no code yet).

## Notes

- `3DFACE` is stored by both parsers as a `solid` with `outlineOnly: true`; that mark is the
  contract this module relies on, and it is documented in the ODD record.
- Not included: per-face colours, smoothing, UVs, and any ACIS support.
